# RPG-Game
This is an action RPG prototype developed as part of a Unity course.

A build of the game can be played here:
https://nicolasboyer.itch.io/action-rpg-tech-demo

A demo can be viewed here:
https://www.youtube.com/watch?v=KRDKxss19OQ

# Features:
- Combat with 3 different weapons (Sword, Bow, Fireball)
- Different enemy types (Archer, Melee)
- Save states
- Experience and level ups
- Cutscenes and dynamic camera
